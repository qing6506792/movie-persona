# MoviePersona 影格

> 如果你的人生是一部电影，你会是什么角色？

MoviePersona（影格）是一个面向电影爱好者的电影人格探索与电影偏好选择开源项目。大学生是首批推广人群，但网站面向所有喜欢电影的人。

**当前版本：V0.0.7，早期开发中。** 已有一套完整的娱乐型电影人格测试（12 种人格），结果可保存为 PNG 人格卡片；另有一个电影偏好选择原型。个性化电影推荐尚未实现。

## 技术栈

- Next.js（App Router）
- React 19
- TypeScript
- Tailwind CSS v4
- Lucide React（图标）
- 浏览器原生 Canvas 2D API（图片导出，无额外依赖）
- npm

## 本地启动

需要 Node.js 20.9 或更高版本。

```bash
npm install
npm run dev
```

然后在浏览器打开 http://localhost:3000 。

常用检查命令：

```bash
npx tsc --noEmit
npx eslint .
npm run build
```

## 已实现功能

### 电影人格测试 `/quizzes`

测试标题：《你的人生拿了哪种电影剧本？》——7 个离谱镜头，测出你的片场人设。

- 7 道正式测试题：Q1–Q4 每题 4 个选项，Q5–Q7 每题 3 个选项，逐题展示并显示进度。
- 未作答不能进入下一题；可以返回上一题，已选答案会保留。
- 完成后可以返回修改答案，结果按最新答案重新计算。
- 12 种娱乐型电影人格，由两个维度组合而成：
  - 电影本能：感受 / 洞察 / 即兴 / 破局
  - 剧情气质：慢镜头 / 高能剧情 / 荒诞奇幻
  - 12 种人格：雨夜漫游者、极光追猎者、白日梦游师、暗室观察员、反转捕手、平行时空记录员、午夜放映员、失控特技演员、彩蛋特工、片尾改写者、片场出逃者、镜外导演。每种人格有独立的一句话文案、描述、3 个关键词、B 面属性和配色。
- 结果卡：每种人格有独立的称号、一句话文案、描述、3 个标签、配色与装饰图案，全部由 CSS、SVG 和 Lucide 图标绘制。
- 一键复制分享文案：文案随人格动态变化。复制成功显示"已复制"；复制失败时提示点击文字框，全选后手动复制。
- 保存为 PNG：结果页的"生成图片"会在本地用 Canvas 绘制一张 1080 × 1440 的电影票根风格人格卡片，可预览并下载。
- 可以随时重新测试，旧答案和结果会被清空。
- 结果页注明：本测试仅供娱乐，不代表专业心理评估。

### 计分规则

计分是确定性的纯函数（`src/lib/scoring.ts`），没有随机数：

1. Q1–Q4 的每个选项对应一种电影本能，Q5–Q7 的每个选项对应一种剧情气质，选中则该类别得 1 分。
2. 两个维度各自决出最高分类别，再组合成 12 种人格之一。
3. 某个维度出现最高分并列时，在该维度内从最后一题往前查看，选择最近一次被选中的并列类别。
4. 答案缺失或无效时直接拒绝，不会给出默认人格。

选项与类别的对应关系只存在于题库数据中，页面不会展示。各题选项的类别顺序有意错开。

验证：`node scripts\verify-personas.mjs` 会调用生产用的计分函数，遍历全部 4⁴ × 3³ = 6912 种答案组合，确认 12 种人格均可达，并检查平局规则、无效答案拒绝和人格数据格式。
选项与人格的对应关系只存在于题库数据中，页面不会展示。各题选项的人格顺序有意错开。

### PNG 人格卡片

- 固定 3:4 竖版，1080 × 1440 像素，背景不透明。
- 使用 Canvas 原生文字、渐变和几何图形绘制，字体为系统字体，不使用外部图片、网络字体或跨域资源。
- 人格名称、文案、标签、描述和配色读取自 `src/data/personas.ts`，与页面结果卡一致；四种人格的纹样不同，排版一致。
- 图片中没有网址、二维码、评分、稀有度或人群占比，也不使用任何电影海报或剧照。
- 预览使用原生对话框，可用键盘 Esc 或"关闭"按钮关闭；关闭、重新生成和离开页面时会释放临时图片地址。

已知限制：

- 下载依赖浏览器对 `download` 属性的支持。如果没有开始下载，请长按图片（手机）或右键图片另存为（电脑）；页面不会声称"已保存"。
- 图片中的中文使用用户设备上的系统字体，不同系统的字形会略有差异。
- 目前只在桌面 Chrome 内核浏览器上做过实际验证，iOS Safari、Firefox 等尚未验证。

### 电影偏好选择 `/discover`

- 16 部真实电影的本地静态样本（片名、年份、类型；简介为项目原创）。
- 按片名实时搜索，按类型筛选，两者可同时生效；搜索与筛选不会清空已选电影。
- 点击选择，再点击取消；实时显示已选数量，至少选 5 部才能进入确认视图，选满后不会自动跳转。
- 确认视图可以返回修改，选择不会丢失。确认后只显示"偏好已在当前页面确认"，没有任何推荐结果。
- 偏好集合（Cold-start Seed Set）是用户主动选择的静态电影集合，**不是**观影历史、点击日志或评分序列，也不是序列推荐模型的训练样本。

### 其他

- 首页：Hero、功能介绍、用户体验流程。
- `PosterCard` 原创封面组件：不使用任何真实海报，标签为"原创占位封面"。
- 响应式布局，支持键盘访问和"减少动画"系统设置。
- GitHub 仓库地址与站点公开地址集中配置。

## 隐私与数据

- 无登录，无数据库，无后端接口。
- 无持久化：不使用 localStorage、sessionStorage 或 Cookie。测试答案和电影选择只保存在当前页面的 React 内存里，刷新页面后会重置。
- 不上传任何用户回答或选择，没有用户行为追踪。
- PNG 图片在浏览器本地生成，不经过任何服务器。

## 人格测试与电影偏好选择是独立的

- 人格测试结果不会带到 `/discover`，也不会用于电影推荐。
- `/discover` 中选择的电影不会影响人格测试。
- 目前没有经过验证的"人格到电影"映射，因此项目不展示任何人格专属推荐。

## 项目结构

```text
src/
  app/                 页面与路由
    page.tsx           首页
    quizzes/           电影人格测试页
    discover/          电影偏好选择页
  components/
    home/              首页各区块
    quiz/              QuizRunner（测试流程）、ResultPanel（结果卡与复制文案）、
                       SavePersonaCard（图片预览与下载）
    movie/             MovieSelector（偏好选择）、PosterCard（原创封面）
  data/
    quizQuestions.ts   7 道测试题与选项的人格归属
    personas.ts        四种人格的文案、配色与分享文案生成
    movies.ts          16 部电影的本地静态样本
  lib/
    scoring.ts         计分纯函数
    personaCard.ts     Canvas 人格卡片绘制与 PNG 导出
  types/               Movie、Quiz 等类型
  config/
    site.ts            站点信息、GitHub 地址、站点公开地址
```

`QuizDemo.tsx`、`demoQuiz.ts`、`PreviewPage.tsx` 为早期原型遗留文件，当前没有页面使用。

## 配置

`src/config/site.ts` 中有两处可配置地址：

```ts
githubUrl: "https://github.com/你的用户名/movie-persona",
siteUrl: "", // 部署后填写，例如 "https://example.com"
```

- `githubUrl` 为空时，导航栏和页脚显示"GitHub 待配置"，不会跳转；只有以 `https://github.com/` 开头才被视为有效。
- `siteUrl` 为空时，分享文案不附带任何链接；只有以 `https://` 开头才被视为有效。
